# Smart Pantry API

AI-powered Smart Pantry backend using FastAPI.

## Features

- OCR Receipt Scanner
- Pantry Management
- Shopping List
- Recipe Recommendation
- Gemini AI
- Expiry Prediction

## Installation

```bash
git clone https://github.com/USERNAME/smart-pantry-api.git

cd smart-pantry-api

pip install -r requirements.txt
```

Run

```bash
uvicorn app.main:app --reload
```

Open

```
http://127.0.0.1:8000/docs
```
